# Example projects / 示例项目

`main.py`, `hello.c`, `hello.cpp` and `input_demo.py` run as single files.

For a multi-file example, use **打开文件夹 / Open folder** to select **c-project** or **cpp-project** itself as your workspace. Then open `main.c` or `main.cpp` and press **F5**. Both print a total of **42**. Each project includes its own `.codestudio.json`; configuration is read from the workspace root.

单文件示例直接按 F5。多文件示例需要先通过“打开文件夹”选择 **c-project** 或 **cpp-project 目录本身**，再打开入口文件按 F5。输出的总和为 **42**。项目配置位于各自根目录的 `.codestudio.json`。
