# v0.3 编辑器、AI 与升级

## 本地智能补全

Windows 安装包自带 Pyright 1.1.414 和 clangd 23.1.0，不需要启动时联网下载。Python、C/C++ 支持成员补全、参数提示、悬停说明、F12 跳转到工作区内定义和实时错误标记。语言服务会使用打开文件中尚未保存的编辑；代码仍由你保存。

Python 使用项目设置中生效的解释器与虚拟环境解析第三方包。C/C++ 使用项目源文件、头文件目录、语言标准与已检测的编译器生成分析配置。配置变更后下次编辑或查询会重新启动语言服务。编译器需要另外安装，语言服务不代替编译和运行。

普通补全不调用 AI。服务缺失或启动失败时保留关键词与片段补全，终端上方显示状态。大型项目、复杂宏及未配置的外部库可能需要额外配置。当前 F12 只打开工作区内文件；标准库和环境中的外部文件不会自动打开。语法与类型诊断也不能保证程序逻辑正确。

“问题”面板可点击错误跳到对应位置，也可选择“请导师解释”。有任务时只解释当前步骤，无任务时使用普通 AI 对话。

## AI 流式回答

对话支持 Chat Completions、Responses 和 Anthropic Messages 的文本流。回复逐段显示，可停止和重试；停止会取消本机到服务商的请求，服务商可能仍按已生成内容收费。

设置中的“流式回答”可关闭。服务返回普通 JSON 时直接显示结果；只有明确拒绝 stream 参数时才自动改用普通请求。断线、服务错误或回复中途失败不会自动重新请求，避免重复调用。停止或不完整的回复不作为后续完整助手答案发送。

## 导师提示深度

手动检查与提问可选择：轻提示、详细思路、当前步骤示例。示例以代码块显示，不自动修改文件。自动检查始终使用轻提示。原有暂停、请求间隔、每小时上限与确认推进仍生效。

## 中英文界面

右上角选择中文或 English，立即生效并保存到本机。新 AI 请求也要求使用所选语言。已经生成的导师路线、对话和用户代码保留原内容。

## 升级与备份

先保存打开的文件，停止旧版本，再把新版本完整解压到新文件夹并启动。

- **从 v0.1/v0.2 升级：** 打开“设置 → 升级与备份”，填写旧工作台文件夹，例如 `G:\CodeStudio`，点击迁移。只读取旧版本 `data/settings.json` 与导师进度，不修改旧文件和代码。
- **后续升级：** 导出加密备份，在新版本导入。备份包含 API 地址、模型、加密密钥、界面语言、工具路径及导师进度。工作区路径需要仍然存在。
- **恢复本机备份：** 页面列出最近 20 份备份。首次读取旧设置和恢复前自动建立备份，位于 `data/backups`；恢复失败会尝试回滚。

备份使用 Windows 当前账户保护，只能在同一电脑、同一账户下恢复。跨电脑请重新填写密钥。代码、虚拟环境、浏览器草稿、运行日志与第三方依赖不包含在备份中，需分别保存；备份文件也不要提交到 GitHub。

源码开发者先运行 `npm ci` 和 `npm run prepare:languages`，再构建。语言组件下载后会校验固定 SHA256；构建与打包过程会联网，安装包启动和普通编辑无需联网。
