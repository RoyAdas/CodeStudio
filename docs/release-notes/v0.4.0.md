# CodeStudio v0.4.0

This version adds Python debugging and test-backed guided learning, plus reviewable AI code changes.

- Bundled debugpy: gutter/F9 breakpoints, pause at entry, continue, pause, stepping, workspace call stack and variable values. Uses the project's effective Python environment.
- Python unittest panel with real per-case outcomes, failure details, cancellation and source fingerprints. Failed, interrupted, empty or stale tests cannot pass mentor acceptance.
- AI changes and test generation with side-by-side differences, file selection, explicit draft acceptance and undo. No automatic save or execution; stale draft and path guards apply.
- Chinese/English UI, existing AI providers, local launch, environments, completion and encrypted upgrade migration remain supported.

## Download and start / 下载与启动

Download `CodeStudio-v0.4.0-windows-x64.zip`, extract the entire folder and double-click `Start.cmd` or `启动工作台.cmd`. Windows x64 is supported. The package includes Node, editor assets, language services and debugpy. Python and C/C++ compilers require separate installation. Python debugging requires Python 3.10 or a newer Python 3.

下载 Windows 包并完整解压，双击启动脚本。左侧“调试”可观察 Python 执行状态，“测试”可运行 unittest，编辑器工具栏可预览 AI 修改。AI 使用自己配置的接口。

## Upgrade / 升级

Save files and stop the old version. Extract into a new folder and use Settings → Upgrade & backup to migrate the old workbench folder, such as `G:\CodeStudio`, or import its encrypted backup. Encrypted keys require the same computer and Windows account. Code and environments remain in their original workspace.

保存并停止旧版，将新版解压到新文件夹，在“设置 → 升级与备份”迁移旧文件夹或导入备份。

See the [中文指南](../workflow.zh-CN.md) / [English guide](../workflow.en.md). C/C++ debugging, Git UI, formatting/rename, pytest, debugger expression evaluation and interactive debugging stdin are outside v0.4.0's scope. Normal interactive Run remains available.
