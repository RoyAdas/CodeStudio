# 使用说明

[中文](usage.zh-CN.md) · [English](usage.en.md) · [返回 README](../README.md)

## 启动与停止

下载 Windows x64 Release 压缩包并完整解压到可写文件夹，双击 `Start.cmd` 或 `启动工作台.cmd`。保留 `runtime/`、`dist/`、服务文件和启动脚本。浏览器会自动打开 `127.0.0.1` 地址，不经过外部网站托管。

如果默认 8765 端口被占用，启动器会选择 8766–8784 中的可用端口。再次启动会复用同一安装目录的服务。关闭浏览器不会停止服务；双击 `Stop.cmd` 或 `停止工作台.cmd` 停止服务和正在执行的程序。

## 运行环境

启动包自带 Node。Python 程序需要安装 Python；C/C++ 需要 GCC/G++ 或 Clang/Clang++。安装后可把工具加入 PATH，或在“设置 → 运行环境”填写解释器及编译器的完整路径，保存后重新检测。项目依赖（例如 PyTorch）仍需由你在对应 Python 环境中安装。

一键启动指启动工作台，不表示自动安装所有编程语言与依赖。v0.2.0 只支持 Windows x64。

## 文件与快捷键

左下角“打开文件夹”选择项目路径；文件保存会直接写入所选目录。上方按钮可新建文件和目录。随附的 `examples/` 包含 Python、C/C++ 与标准输入示例。

| 操作 | 快捷键 |
| --- | --- |
| 保存当前文件 | Ctrl + S |
| 保存并运行 | F5 |
| 普通补全 | Ctrl + Space |
| AI 补全 | Ctrl + Alt + Space |
| 快速打开文件 | Ctrl + P |
| 文件内查找 | Ctrl + F |
| 撤销编辑或 AI 插入 | Ctrl + Z |

普通补全包括 Python/C/C++ 关键字、片段和当前文件符号，不需要 API。使用方向键选择，Enter 或 Tab 确认，片段使用 Tab 移到下一项。它不包含语言服务器提供的完整类型与成员分析。

未保存内容会存为当前浏览器中的本机草稿，刷新后可恢复。Ctrl+S 才会写入文件；运行前也会保存。草稿不是备份，清除浏览器数据可能删除草稿。

## 运行程序

支持 `.py`、`.c`、`.cpp`、`.cc`、`.cxx`、`.js` 和 `.mjs`。C/C++ 默认单文件编译，默认标准为 C11/C++17。在“项目设置”选择多个源文件可构建项目，也可选择 Python 虚拟环境。F5 会保存所有打开的修改；详见 [项目环境与构建](project.zh-CN.md)。

终端显示实际输出、错误和退出码。需要标准输入时，在终端底部输入并按 Enter；EOF 按钮表示输入结束。运行参数中含空格的参数用引号包围。“停止”终止当前程序。程序默认运行上限为 120 秒，可在设置中调整为 10–600 秒；每次源文件编译或链接的上限为 30 秒。

程序以当前 Windows 账户的权限执行，不是隔离沙箱。不要运行不可信的代码，也不要把服务转发到公网。

## 配置 AI

点击右上角齿轮，在“AI 服务”填写：

1. 服务类型：自定义兼容接口、DeepSeek、Ollama 或 Anthropic 兼容接口。
2. 协议：Chat Completions、Responses 或 Anthropic Messages，按服务商要求选择。
3. 地址：基础地址或完整接口路径。服务商要求 `/v1` 时需填写完整。
4. 模型：该服务允许使用的完整模型名称。
5. 密钥：只在设置页填写；无需密钥的本机接口可勾选对应选项。

“测试连接”会产生一次短请求，可能收费。适配已用本机模拟接口验证；不同真实服务仍可能有参数、响应格式或访问限制。

密钥由当前 Windows 账户通过 DPAPI 加密，存于 `data/`。更换服务地址会清除旧密钥。迁移电脑或更换账户后需要重新填写，不要上传配置文件或向 Issue 粘贴密钥。

AI 补全先展示建议，经确认后插入，可用 Ctrl+Z 撤销。普通 AI 对话的代码上下文按钮控制相关文件内容是否随消息发送。**实时导师单独使用打开文件快照，开始任务后可以自动发送；对话上下文开关不控制导师。** 具体范围和暂停方法见 [导师说明](mentor.zh-CN.md)。

## 排错和更新

- 缺少解释器或编译器：安装所需工具，在运行环境设置中填写路径并保存。
- 浏览器未打开：查看启动脚本显示的地址，也可查看 `data/server-error.log`。日志可能含本机路径，反馈前请删去私人内容。
- API 失败：核对地址、协议、模型权限、密钥与额度；导师失败会暂停自动检查，解决后手动恢复。
- 替换安装包：先停止服务，备份所选工作区和需要保留的本机配置，再更新。密钥只能在原 Windows 账户和电脑上使用。

`data/` 保存配置、导师进度和日志。代码保存于你选择的工作区，可能在安装目录之外。备份代码前先确认实际工作区路径，停止服务后再移动整个安装目录。
