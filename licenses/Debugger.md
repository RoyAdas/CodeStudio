# Python debugger

The Windows package includes debugpy 1.8.22 from Microsoft's official PyPI release:
https://pypi.org/project/debugpy/1.8.22/

The original wheel, including debugpy, vendored dependencies and upstream notices,
is extracted under `debug-runtime/lib`. Its license is retained at
`debug-runtime/lib/debugpy-1.8.22.dist-info/licenses/LICENSE`.

debugpy is distributed under MIT. Vendored pydevd and other components retain
their original notices and license terms in the wheel and its LICENSE document.
See that document for the complete upstream attribution and terms.
