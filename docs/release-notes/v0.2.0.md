CodeStudio v0.2.0 — 项目环境与多文件构建 / Project environments and builds

这一版让本地工作台从单文件练习扩展到项目运行，保留一键启动、自定义 AI 接口和实时导师。

## 新增 / Added

- **项目设置**：每个工作区用自己的 `.codestudio.json` 保存配置。
- **Python 虚拟环境**：自动识别、仅用虚拟环境或系统 Python；点击创建新环境，已有目录不会覆盖。
- **C/C++ 多文件构建**：选择源文件、头文件目录和语言标准；支持混合 C/C++ 链接。
- **F5 保存并构建**：运行前保存所有打开的修改，列表留空时仍支持单文件运行。
- **中文路径兼容**：保留原始诊断文件名和行号，构建完成、失败或停止后清理临时文件。
- 中英文项目指南与 C/C++ 双文件示例。

This release adds workspace-specific project settings, Python virtual-environment selection and creation, explicit multi-file C/C++ builds, mixed-language linking, header directories, and selectable language standards. F5 saves all modified open files before running. Empty build lists preserve single-file execution. Bilingual guides and example projects are included.

## 下载与启动 / Download and start

下载 **CodeStudio-v0.2.0-windows-x64.zip**，完整解压到可写目录，双击 **Start.cmd** 或 **启动工作台.cmd**。安装包内置 Node 24.21.0，Python 与 GCC/Clang 需要另行安装。左侧点击“项目设置”开始配置。

Download **CodeStudio-v0.2.0-windows-x64.zip**, extract the entire archive into a writable folder, and double-click **Start.cmd**. The package includes Node 24.21.0. Install Python and GCC/Clang separately. Open **项目设置 / Project Settings** below the file tree.

## 升级 / Upgrade

先停止 v0.1.0 并备份代码和 `data/`。建议把新版解压到新目录，再打开原来的代码工作区。若需要保留 API 设置与导师进度，可在同一电脑、同一 Windows 账户下把旧 `data/` 复制到新目录；不要复制旧 `running.json` 或日志。移动项目后重新创建虚拟环境。

Stop v0.1.0 and back up your code and `data/`. Extract the new package into a separate folder and open your existing workspace. On the same computer and Windows account, copy old `data/` to retain settings and mentor progress, excluding `running.json` and logs. Recreate virtual environments after moving projects.

## 范围 / Scope

当前支持 Windows x64，界面为中文。尚未集成语言服务器、断点调试、CMake、外部库链接配置和流式 AI 回复。Python 第三方依赖由你自行安装；运行代码使用当前用户权限。AI 配置和协议适配沿用 v0.1.0，真实服务差异仍以服务商为准。

Windows x64 and Chinese UI. Language servers, breakpoint debugging, CMake, external-library link options, and streaming AI are not included. Install Python dependencies yourself. Programs execute with your current Windows account. Existing configurable AI adapters remain; real-provider compatibility depends on the service.
