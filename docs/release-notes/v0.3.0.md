# CodeStudio v0.3.0

This release adds local semantic editing and a smoother guided-learning workflow.

- Bundled Pyright and clangd: Python/C/C++ member completion, signature help, hover, workspace definition navigation and live diagnostics, including unsaved edits.
- Streaming chat for Chat Completions, Responses and Anthropic Messages, with Stop, Retry, a streaming toggle and explicit compatibility fallback.
- Three manual mentor hint levels: light hint, detailed approach and an example for the current step. Automatic reviews retain light hints.
- Encrypted backup/restore, automatic backups before upgrades and restoration, and direct migration from v0.1/v0.2 folders.
- Chinese/English interface switching, saved locally and applied to new AI requests.
- Updated Vite and DOMPurify dependencies.

## Download and launch / 下载与启动

Download `CodeStudio-v0.3.0-windows-x64.zip`, extract the entire folder, then double-click `Start.cmd` or `启动工作台.cmd`. Windows x64 is supported. Node, editor assets and language services are bundled; Python and C/C++ compilers still require separate installation. AI uses your configured provider.

下载 Windows 安装包并完整解压，双击启动脚本即可。普通编辑和语言分析使用本机组件，不依赖网站托管；AI 接口的网络与服务可用性由所选提供商决定。

## Upgrade / 升级

Save open files and stop the old version. Extract v0.3.0 into a new folder. Under Settings → Upgrade & backup, enter your old CodeStudio folder and choose migration. This reads old settings and mentor progress without editing old code. Workspaces and tool paths must remain available. Encrypted keys can migrate only on the same computer and Windows account.

先保存并停止旧版本，把 v0.3.0 解压到新文件夹。打开“设置 → 升级与备份”，填写旧工作台文件夹并迁移，例如 `G:\CodeStudio`。代码和虚拟环境仍留在原工作区。跨电脑或账户时需重新填写 API 密钥。以后升级可导出并导入加密备份。

See [中文说明](../editor.zh-CN.md) / [English guide](../editor.en.md) for behavior, backups and limitations. Existing AI output is not retroactively translated. External-library definition files, a debugger, VS Code extension marketplace and CMake are outside this release.
