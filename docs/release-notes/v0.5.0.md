# CodeStudio v0.5.0

Ten requested capabilities are now available in the local workbench / 十项功能已加入本地工作台。

- Git status, differences, staging, author identity, commits/history, push/pull and AI diff/message suggestions.
- Literal project search/replacement, Python/C/C++ formatting and semantic rename with explicit difference review.
- Local per-file save history, comparison and restore preview.
- Project-file AI context selection, separate chat/mentor sending scope and persistent workspace selection.
- Encrypted AI profiles with separate chat, completion and mentor routes.
- Five offline project templates with skeletons, tests and guided-learning goals.
- pytest parameterized cases, failed-only reruns and branch coverage/editor markings.
- Multiple real PowerShell ConPTY terminal sessions.
- Per-workspace learning progress, mistakes and explicitly saved AI review drafts.
- Manual GitHub update checks, SHA256-verified separate installations, old-version registration and rollback.

## Download and start / 下载与启动

Download CodeStudio-v0.5.0-windows-x64.zip, extract the entire archive into a writable folder, then double-click Start.cmd or 启动工作台.cmd. The workbench opens on 127.0.0.1. No chatgpt.site hosting is used.

下载 Windows x64 安装包并完整解压，双击启动。进入“工具箱”使用新功能。

Packages include Node, language services, debugpy, Black/Prettier, pytest, coverage and native ConPTY support. Python and C/C++ compilers remain separate installations. Python 3.10+ is required for debugging, formatting, pytest and coverage. Git features need Git for Windows; interactive terminals need Windows 10 1809+.

## Upgrade / 升级

Save and stop the old version; extract the new version separately. Use Settings → Upgrade & backup to migrate the previous installation folder or import its encrypted backup. Source projects and virtual environments stay in their original workspace. Use Toolbox → Updates and rollback to register the old installation. Keys require the same Windows account and machine.

保存、停止旧版，新版解压到新文件夹，在“升级与备份”导入旧设置，在“更新与回退”登记旧版。不要覆盖原安装目录。

See the [中文工具箱指南](../workspace.zh-CN.md) / [English toolbox guide](../workspace.en.md) for sending limits, local history retention, native-runtime requirements and migration details. AI adapters are tested using local mocks; not every real provider has been verified. Git remote operations reuse local credentials. C/C++ debugging, arbitrary extensions, CMake and debugger expression evaluation remain outside this release.
