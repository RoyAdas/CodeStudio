CodeStudio v0.1.0 — 首个公开版本 / First public release

一个 Windows 本地 AI 编程学习工作台：你提交任务，自己写代码，实时导师逐步提供提示和检查。

## 下载与启动 / Download and start

下载 **CodeStudio-v0.1.0-windows-x64.zip**，完整解压后双击 **Start.cmd** 或 **启动工作台.cmd**。压缩包内置 Node 24.21.0，无需安装 Node/npm。Python 和 C/C++ 编译器需要另行安装。

Download **CodeStudio-v0.1.0-windows-x64.zip**, extract the entire archive, then double-click **Start.cmd**. The package bundles Node 24.21.0. Install Python and a GCC/Clang toolchain separately to execute those languages. GitHub's automatic source-code archives are for developers.

## 本版功能 / Features

- Monaco 编辑器、文件管理、保存、终端输入及 Python/C/C++ 单文件编译运行。
- 离线关键字、代码片段与当前文件符号补全；可预览并接受 AI 补全。
- 可配置接口地址、模型、密钥，支持 Chat Completions、Responses、Anthropic Messages 适配。
- 实时任务导师：分步规划、停笔与运行后检查、代码行提示、暂停恢复和工作区进度保存。
- 自动检查默认最短间隔 20 秒、每小时上限 30 次；请求计数和服务报告的 Token 用量。
- 中英文 README、使用说明、公开示例、MIT 许可证和第三方授权文件。
- 修正英文 Windows 上 MinGW 编译中文目录/中文源码名时的兼容问题，保留原始源码、行号和相对头文件。

English: local editing and single-file execution, basic offline completion, configurable AI APIs, and a task mentor with idle/run feedback, inline hints, persistent progress, pause controls and automatic request limits.

## 验证与范围 / Validation and scope

类型检查和构建通过；21 项逻辑与接口测试、17 项浏览器导师流程检查、9 项 Windows 安装包检查通过，Python/C/C++ 示例实际运行。AI 测试使用本机模拟服务，未验证所有真实服务及模型。

Type checking, production build, 21 logic/API tests, 17 browser mentor checks and 9 Windows package checks passed. Python/C/C++ examples executed successfully, including Unicode installation paths and filenames with Windows MinGW. AI tests use local mocks; real provider/model compatibility varies.

当前支持 Windows x64，界面为中文。完整 VS Code 扩展、断点调试、多文件构建及语言服务器语义补全尚未集成。

The current UI is Chinese and this release targets Windows x64. VS Code extensions, breakpoint debugging, multi-file builds and language-server completion are not included yet.

开始导师任务后会自动向所选服务发送代码上下文与运行输出；常见敏感文件名默认排除，但这不是内容脱敏。手动请求仍可能收费，统计不等于账单。本机执行的代码具有当前用户权限。编辑与运行的页面使用本地资源，不依赖 chatgpt.site。

Starting a mentor task enables automatic transmission of code context and execution output to your configured provider. Filename exclusions do not redact secrets embedded in ordinary code or output. Manual requests can incur costs. Programs execute with your Windows account's permissions. Editor assets are bundled locally.

**SHA256SUMS.txt** 提供安装包校验值 / contains the package checksum.
