# CodeStudio

[中文](README.md) · [English](README.en.md)

在浏览器里编写和运行本机代码，让 AI 导师按小步骤带你完成自己的项目。

CodeStudio 是 Windows 本地编程学习工作台，使用 Monaco 编辑器，提供 Python、C/C++ 编辑运行、智能补全和可自定义接口的 AI 功能。v0.3.0 增加本地智能补全、流式 AI 对话、分级导师提示、加密备份与旧版迁移，以及中英文界面。

![CodeStudio 工作台：文件树、代码编辑器、运行输出和实时导师](docs/images/workbench.png)

## 下载并启动

1. 下载 [CodeStudio-v0.3.0-windows-x64.zip](https://github.com/RoyAdas/CodeStudio/releases/download/v0.3.0/CodeStudio-v0.3.0-windows-x64.zip)，或查看 [最新 Release](https://github.com/RoyAdas/CodeStudio/releases/latest)。GitHub 的 “Source code” 压缩包是开发源码，不是一键启动包。
2. **完整解压**到可写文件夹。不要直接在压缩包里运行，也不要只复制启动脚本。
3. 双击 `Start.cmd` 或 `启动工作台.cmd`，浏览器会打开本机工作台。

安装包自带 Node，启动时无需安装 npm，也不需要下载编辑器资源。Python、GCC/G++ 或 Clang/Clang++ **需要另外安装**；在“设置 → 运行环境”查看检测结果，或填写工具的完整路径。AI 需要你自行配置服务；编辑与运行不需要 AI 服务。

默认地址是 `http://127.0.0.1:8765`。端口被占用时启动器会选择其他可用端口，请以它打开的地址为准。双击 `Stop.cmd` 或 `停止工作台.cmd` 停止服务。关闭浏览器不会停止后台服务。

当前支持 **Windows x64**。macOS、Linux、手机和公网部署不在 v0.3.0 的支持范围内。

## 可以做什么

- 打开本地项目，管理文件、编辑和保存代码，恢复浏览器中的未保存草稿。
- 运行 Python、JavaScript 程序，以及 C/C++ 单文件或多文件项目，查看真实输出、退出码和编译错误；支持标准输入、停止运行和时间上限。
- 识别或创建项目 Python 虚拟环境，保存每个工作区的运行配置。
- 使用 Python/C/C++ 成员补全、参数提示、悬停说明、工作区内定义跳转和实时错误诊断；普通补全无需 AI。
- 请求 AI 补全、解释代码或排查运行错误；建议经你确认后才插入编辑器。
- 提交自己的学习任务，让导师生成路线，每次给出一个目标、提示和验证方法。
- 默认停笔约 5 秒后及运行结束后检查代码；自动请求至少间隔 20 秒，默认每小时最多 30 次，可调整、暂停或改为手动检查。检查通过后由你决定进入下一步。

在左侧“项目设置”选择 Python 环境、C/C++ 构建文件、头文件目录与语言标准。F5 会保存所有打开的修改，再按项目配置运行；C/C++ 列表留空则继续单文件运行。详见 [项目环境与构建](docs/project.zh-CN.md)。

暂不支持扩展市场、断点调试、CMake 和外部库链接配置。默认 C11/C++17，可选择编译器支持的其他标准。

流式回答、三档提示、备份迁移与界面语言切换详见 [v0.3 编辑器与升级指南](docs/editor.zh-CN.md)。

## 第一次练习

打开随附的 `examples` 文件夹，选择 `main.py`、`hello.c` 或 `hello.cpp`，按 **F5** 保存并运行。`input_demo.py` 可以体验终端输入。

配置 AI 后，可在右侧“实时导师”输入：

> 用 Python 做一个记账小程序。我学过变量、循环和函数，希望每次只做一个小任务，先提示，再检查我的代码。

提交任务后自己写代码。导师检查会发送代码到你选择的服务；不想自动发送时，先暂停导师或选择“只手动检查”。模型返回仍需要时间，5 秒是停笔等待时间，不是完整响应时间。

详细操作见 [使用说明](docs/usage.zh-CN.md) 和 [实时导师说明](docs/mentor.zh-CN.md)。

## 连接自己的 AI

在“设置 → AI 服务”填写 **API 地址、接口协议、模型名称和密钥**。支持 Chat Completions、Responses 和 Anthropic Messages 协议，可配置兼容的中转站、DeepSeek 或本机 Ollama。无需密钥的接口可勾选对应选项。

请使用服务商提供的准确地址和模型名。代码包含这些协议的适配和模拟测试，但不同服务的网络、模型权限、参数及响应格式会有差异，**尚未逐一验证所有真实服务**。“测试连接”会发送一次简短请求，可能消耗额度；自动导师也会产生 API 用量。每小时上限只限制自动检查，手动请求仍可能收费。界面中的 token 统计来自服务返回值，部分服务不返回用量，统计不等于账单。

## 隐私与运行权限

- 编辑器资源由本机提供，服务只监听 `127.0.0.1`。编辑、普通补全和运行代码不会调用 AI。
- 主动使用 AI 对话或补全会发送相关上下文；**开始导师任务后，开启的自动检查会持续发送代码快照**。导师最多使用 6 个打开文件、约 36,000 字符，也可能包含选中代码、任务及运行输出。导师默认排除 `.env` 等常见敏感文件名，但不进行内容脱敏；代码或输出中的密钥仍可能发送。遇到这类内容请暂停导师或先移除它，具体排除规则见 [导师说明](docs/mentor.zh-CN.md)。
- API 密钥通过 Windows DPAPI 使用当前账户加密保存在本机 `data/`，换账户或电脑后需重新填写。任务记录、配置和日志也在 `data/`，请勿上传到 GitHub。
- 程序以当前 Windows 用户权限执行，**不是隔离的代码沙箱**。请只运行自己信任的代码，不要把工作台暴露到公网。
- AI 反馈是模型判断，不代替实际测试。导师不会自动安装依赖、执行任意命令或覆盖你的代码。

## 从源码开发

需要支持本项目构建的 Node.js 版本（参见 `package.json` 的 `engines`）与 npm。在仓库根目录执行：

```sh
npm ci
npm run prepare:languages
npm run build
npm start
```

随后打开启动信息中的本机地址。`npm start` 提供构建后的界面；修改前端后需要重新构建。

验证与 Windows 打包：

```sh
npm run typecheck
npm test
npm run test:e2e
npm run package:win
```

首次运行端到端测试前安装测试浏览器：`npx playwright install chromium`。测试使用本机模拟 AI 接口，不需要真实 API 密钥。Windows 打包会生成带 Node 运行时的 ZIP；以打包脚本输出的文件位置为准。

仓库只保存源码、示例和文档，`data/`、个人工作区、运行时及构建产物不提交。详见 [贡献指南](CONTRIBUTING.md)。
