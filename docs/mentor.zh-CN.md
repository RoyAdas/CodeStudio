# 实时任务导师

[中文](mentor.zh-CN.md) · [English](mentor.en.md) · [返回 README](../README.md)

## 从自己的任务开始

1. 打开要练习的工作区及相关代码文件，在设置页配置自己的 AI 服务。
2. 在右侧“我想完成的任务”填写目标，并选择基础。例如：用 Python 做一个记账程序，我学过函数，希望先提示，再检查。
3. 点击“提交任务，开始指导”。导师生成分步路线，给出第一步目标、提示和验证方法。
4. 自己编辑代码。默认停笔约 5 秒后以及运行结束后检查。模型响应还需要时间，5 秒只是停笔等待。
5. 参考右侧反馈和代码行提示，必要时按 F5 验证。反馈里的文件和行号可以点击跳转。
6. 当前代码通过检查后，点击“进入下一步”。步骤不会自动跳过，也不会自动覆盖你的代码。

没有开始任务时，不会自动调用导师。AI 判断可能出错，应按每步的验证方法实际运行，不能把“通过”当成程序正确性的保证。

## 控制自动检查和用量

- “暂停 / 恢复”控制自动检查；暂停会取消等待中的导师请求。
- “自动检查”可选停笔和运行后、仅运行后或只手动检查。
- 自动请求最短间隔可选 20、30 或 60 秒，快速修改会合并成最新快照。
- 默认每小时最多 30 次自动检查，可改为 10、30、60 次或不限制。这个上限不限制提交任务、手动检查和追问。
- “检查这一步”发起手动检查；下方问题框用于询问当前步骤。
- 页面不可见时不发起自动检查。编辑、保存和运行无需等待导师。

导师使用你配置的接口，所有实际请求都可能收费。界面统计请求数以及服务返回的 token 用量；有些服务不返回 usage，统计不是费用估算，也不等于服务商账单。使用昂贵模型前建议先采用手动模式，确认服务商的计费规则。

网络、权限、额度或模型返回格式出错时，自动检查会暂停并保留进度。解决后再恢复，避免反复失败消耗额度。已取消的请求仍可能已由服务处理，取消不保证退回费用。

## 导师使用的内容

上下文来自当前和其他打开的代码文件，最多 6 个、约 36,000 字符，包含未保存的编辑内容。也可能包含任务、所选代码和程序实际输出。较长文件会截取，必要时先打开相关的小文件。

导师默认按名称排除以下文件或目录，匹配不区分大小写：

- `.env` 和 `.env.*`。
- 扩展名为 `.pem`、`.key`、`.p12`、`.pfx`、`.keystore` 的文件。
- 名为 `credential`、`credentials`、`secret`、`secrets` 的文件，或这些名称后跟扩展名，例如 `credentials.json`。`secret_config.py` 这类包含单词但不满足规则的名称不会自动排除。
- `id_rsa`、`id_ed25519`、`id_ecdsa`，以及这些名称后跟扩展名的文件。
- 路径中含 `.git`、`.ssh`、`.aws` 或 `data` 目录的文件。

**文件名过滤不等于内容脱敏。** 普通源代码、任务文本、选中代码或终端输出如果包含密钥和私人信息，仍可能发送。请先暂停导师，或移除这些内容再继续。普通对话与 AI 补全仍由你主动请求及各自上下文控制，此排除仅用于导师，不是全局数据保护。

开始任务并开启自动检查表示这些上下文会发送到你填写的服务地址。服务商如何保存或使用数据取决于它的政策。工作台在本机运行不代表使用远程 AI 时所有数据都留在本机。

## 当前代码与运行证据

代码变化会使旧检查失效。旧版本的程序输出不会作为新版本已经验证的证据；进行中的检查遇到新编辑时会取消，稍后检查最新版本。通过后再改代码，也需要重新检查才能推进步骤。

反馈区分静态代码检查与代码加运行结果。导师不执行任意新命令、不安装软件、不自动改写代码。依赖安装和程序行为由你确认。

## 保存与恢复

任务路线、当前步骤和近期反馈保存在本机 `data/mentor-sessions.json`，刷新或重启后可恢复，不同工作区各自保存任务，暂停状态也会保存。这个文件可能包含私人任务或代码反馈，不要提交到仓库。

“新任务”会询问是否结束当前任务。确认会清除当前任务进度，不删除代码。重要代码和需要保留的学习记录请另外备份。
